# Cyberpunk illustrations

The hero illustration was generated with the built-in ImageGen tool, then copied into this project. Responsive WebP exports were resized/compressed with Sharp; the generated composition was not retouched. The original remains in the local generated-images library and ignored `.local` directory.

Project assets:

## Final generation prompt

Use case: stylized-concept. Asset type: original illustration for a software engineering portfolio hero. Create a polished cyberpunk editorial 3D illustration of a compact futuristic developer workstation floating in a dark void: a single angular terminal with a luminous cyan wireframe cube hovering above it, a small handheld device docked beside the terminal, and precise circuit traces linking them. Style: illustrated isometric hard-surface forms, tasteful graphic-novel shading and subtle print grain, precise cyan and acid-yellow edge highlights with tiny magenta accents. Background solid near-black navy #080c14, not transparent. Composition: square, centered main object filling 75 percent of image, generous dark breathing room, all objects fully visible. Clear silhouette, medium detail, no photorealistic person, no city skyline, no logos, no letters, no typography or readable text, no fake interface screenshot. Intended to communicate curious practical software experimentation. No excessive bloom, no rainbow gradients, no decorative particles.

## Animated hobby-project flows — 28 October 2026

All four projects are explicitly described as personal hobby projects. Each now
has a distinct native SVG flow illustration, with four explanatory stages:

- FieldNest: cyan device → durable queue → version check → acknowledgment/review.
- SlotSure: yellow competing requests → shared lock → commit → conflict outcome.
- Coincela: pink imported records → review → confirmed branching allocation → audit.
- Face54: violet cube input → physical validation → worker → confirmed turns.

Project animations include pause/play, next-step and direct stage selection.
Selecting a stage or advancing manually pauses autoplay. Offscreen illustrations
stop animating; step timers avoid work when the browser tab is hidden. System
reduced-motion preference disables autoplay and CSS motion while preserving all
manual controls and the complete explanatory text. Existing deterministic
scenarios remain available through native details on the case-study routes.

Hero workstation artwork now gently floats and scans, and the About circuit
shows a moving signal; both have independent pause controls. No new raster
artwork or animation library was required. Visual flows remain conceptual and
are not connected to the underlying applications.
