## Disclosure structure
Homepage: name, problem, short description, stack and static conceptual artwork,
with direct case-study/repository/contact links.
Case study: screenshot where available, personal motivation, contribution and
hands-on check. Optional native details reveal the animated flow, implementation,
test evidence/limitations, and separate illustrative scenario.
Animations play once and settle; replay/pause/step remain available. System
reduced-motion preference prevents autoplay and CSS motion.
